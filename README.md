## 🛠️ How to Compile & Run

To run programs locally:

1. **Navigate to the target module directory**:
   ```bash
   cd Module-1   # Or Module-2, Module-3, Module-4, Module-5, Module-6
   ```

2. **Standard Java Console / GUI Programs (Modules 1–4)**:
   ```bash
   # Compile
   javac <FileName>.java
   # Example: javac Q1ATMWithdrawalSystem.java

   # Run
   java <ClassName>
   # Example: java Q1ATMWithdrawalSystem
   ```

3. **Servlet Web Application (Module 5)**:
   ```bash
   cd Module-5/FeedbackApp
   # Quick Build:
   build.bat
   # Or manual:
   javac -cp "lib/javax.servlet-api.jar" -d "web/WEB-INF/classes" src/com/example/FeedbackServlet.java
   cd web && jar -cvf ..\FeedbackApp.war *
   # Deploy FeedbackApp.war into Tomcat webapps directory and open http://localhost:8080/FeedbackApp/feedback.html
   ```

4. **Swing & JDBC Desktop Application (Module 6)**:
   ```bash
   cd Module-6/EmployeeManagement
   # Quick Run:
   run.bat
   # Or manual:
   javac -cp "lib/mysql-connector-java.jar" -d bin src/com/example/*.java
   java -cp "bin;lib/mysql-connector-java.jar" com.example.EmployeeForm
   ```
